# PizzaGo — JavaScript endterm stage

**Group:** Aruzhan Amerkhanova, Arai Uakyt, Sulukhan Aizharykova · SE-2529

A six-page, responsive student website for pizza delivery in Astana. The previous commit is the static midterm baseline. This version adds an array-driven menu, search, categories, sizes, a persistent cart, PIZZA10, form validation and a one-minute order tracking demonstration. jQuery interactions follow in the next commit.

Open index.html with an internet connection for Bootstrap 5.3.8, loaded from jsDelivr. No build or installation is needed. A local static server can also be used.

Pages: Home, Menu, Deals, Cart, Track order and Contact. Add a dish on Menu, review Cart, submit valid delivery details and follow the confirmation link to Track order. PG1024 is a standalone demo. Both forms show custom JavaScript validation errors. No real orders, payments or messages are sent.

The site includes semantic HTML, tables, forms, Bootstrap grid and utilities, CSS Flexbox, CSS Grid, relative positioning, and media queries at 991.98px and 575.98px.

Published main branch: https://xelllion.github.io/PizzaGo_midterm/ — this development branch is published only after merge.
